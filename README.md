# Chainloom

本地运行的 EVM 钱包管理与单次、批量转账桌面应用，Python 3.13+，无需部署服务。

支持 Ethereum、BNB Smart Chain、Base 和 X Layer，通过 PySide6 原生界面管理加密钱包库、选择本地钱包签名、预览与确认转账，以及查询交易记录和恢复状态。

## 安装与启动

```sh
uv sync --locked
uv run chainloom-desktop
```

也可使用构建后的 macOS 应用。安装、构建与安全边界详见 [macOS 桌面版文档](docs/macos.md)。

## 钱包与转账

启动后默认打开“钱包管理”，通过“钱包列表 / 资产余额”两个页签整理钱包和查看资产。创建钱包库并设置密码，批量导入私钥后，可搜索、分组、重命名及锁定钱包；在列表双击或右键菜单中可复制完整钱包地址。资产余额页共享搜索、分组与选择，支持明确查询范围、管理查询代币、数值排序和失败项重试，结果按网络在本次解锁期间保留。操作方式及存储边界见 [桌面版文档中的钱包管理说明](docs/macos.md#钱包管理)。

转账页选择网络、本地发送钱包与资产，填写收款地址和数量，预览并确认后在本机签名、通过 RPC 广播。支持原生币和 ERC-20 转账，无需连接外部钱包。

从侧边栏进入“批量转账”，可创建一对多分发、多对一归集和多对多清单，每批最多 100 笔、单一网络和资产。在转账页选择钱包、手动录入或导入 CSV，默认手动填写数量。多对一模式提供“按余额归集”，自动计算可转数量并预留手续费，也可设置每钱包额外原生币预留。计算只回填清单，仍需预览确认后逐笔签名，上一笔确认后再发送下一笔。批次可暂停、手动恢复或结束，并可导出结果，详见 [批量转账说明](docs/macos.md#批量转账)。

网络使用内置公共 RPC，也可在“设置”中配置自定义节点；配置保存在应用数据目录的 `settings.json`，无需额外的网络配置文件或 RPC 环境变量。

## 交易记录与恢复

签名后、广播前将交易哈希和签名交易保存到本地。网络断开或结果不明确时，先在交易记录中刷新状态；必要时“重播原交易”，只广播同一份签名字节，不创建新付款。

同一网络、同一钱包存在待确认交易时，会阻止新付款。不要切换数据目录绕过限制；本地锁无法协调其他工具或其他电脑上的操作。

## 本地数据与日志

可从“设置 → 打开本地数据文件夹”找到钱包库、交易数据库和设置文件。私钥逐个加密保存，名称、地址和分组是明文索引。备份前锁定钱包库并等待后台操作停止，单独保管密码。

macOS 错误日志自动保存到 `~/Library/Logs/Chainloom/chainloom.log`，可从“设置 → 打开日志文件夹”访问；支持自动轮转及敏感信息保护。

## 构建 macOS 安装包

```sh
uv run python scripts/build_macos.py --dmg
```

输出 `.app` 和 `.dmg`。正式分发所需的签名、公证及其他限制见 [macOS 桌面版文档](docs/macos.md)。
